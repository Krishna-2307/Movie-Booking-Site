<h1 align="center">🎬 Movie Booking System</h1>

<p align="center">
A modern and interactive front-end movie booking website where users can explore trending movies, sign up with personal preferences, and submit feedback for future content. Ideal for academic demos or beginner-level full-stack projects.
</p>
